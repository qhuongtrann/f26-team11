## Description 
> ErrandRunner is a platform designed for small daily chores/tasks that elders or people with restricted mobility, might need assistance in fulfilling said tasks. The system allows for the customers to request items to be delivered to their doorstep, which in turn also provides others with job opportunities.
>

## App Functions
1. Customer (the user with the customer role):
    1. Create/modify customer profile - Register as a customer and request items to be fulfilled by the provider.
    2. View available services - Request an errand/task to be completed by a provider/runner.
    3. Subscribe to available services - Subscribe for a weekly, bi-weekly, or monthly fulfillment of items if its a reoccuring necessity, such as, groceries.
    4. Write reviews for subscribed services - Leave Feedback on the speed, efficiency, providers, and overall efficiency of the system.
2. Provider (the user with the provider role):
    1. Create/modify/remove provider profile - Runners register with their name, age, service radius/boundaries, specific aid capabilities (deliveries, grocery delivery, heavy lifting works,...)
    2. Create services - Runners will be able to browse/filter specific request categories based on their specialties, review task specifications (distance, items, payout), accept/decline orders, and update order's status (Pending, In-progress, Completed)
    3. View customer statistics - Runners can view completed deliveries/orders history, active task status, active recurring subscription runs (e.g. weekly grocery), customer ratings/reviews, total earnings. 
    4. Reply to reviews - View and respond to constructive feedback from customers on completed errands and provide solutions to better the services.
